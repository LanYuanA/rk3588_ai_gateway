# RK3588 AI网关项目架构设计与功能模块详解

## 项目概述

RK3588 AI网关是一个基于Rockchip RK3588 SoC的高性能视频处理系统，支持多路视频流的同时拉取、AI推理和推流。该项目充分利用了RK3588的硬件加速能力，包括MPP（Multi-Picture Processing）解码、RGA（Raster Graphic Acceleration Unit）图像处理和NPU（Neural Processing Unit）AI推理。

## 整体架构设计

### 1. 多线程架构
项目采用多线程设计，主要包括以下几个核心线程：
- **拉流/解码线程**（puller_thread）：负责从不同源拉取视频流并进行硬件解码
- **AI推理线程**（inference_thread）：利用NPU进行人脸检测等AI推理任务
- **推流线程**（streamer_thread）：将处理后的视频流推送到RTSP服务器
- **主控制线程**：协调各子线程的生命周期

### 2. 数据流处理
```
视频源 → 拉流线程 → 解码 → RGA缩放 → 推流队列 → 推流线程 → AI推理队列 → AI推理线程 → 检测结果 → 拼接显示
```

## 主要功能模块

### 1. 拉流/解码模块（puller_thread.cpp）
- 支持多种视频源：本地摄像头设备（如/dev/video74）、RTSP流
- 利用GStreamer框架结合MPP硬件解码器进行高效解码
- 自动检测视频格式（H264/H265）并选择合适的解码器
- 将解码后的YUV格式数据转换为RGB/BGR用于后续处理

### 2. AI推理模块（inference_thread.cpp）
- 集成RKNN模型运行时，支持YOLOv8等深度学习模型
- 利用RK3588的NPU进行硬件加速推理
- 实现人脸检测功能，输出检测框和置信度
- 支持多NPU核心并行处理，提高推理吞吐量

### 3. 图像处理模块（rga_resize.cpp, rga_yuv_converter.cpp）
- 利用RGA硬件加速器进行图像缩放、格式转换
- 支持高效的YUV到RGB转换
- 实现DMA32模式以优化内存访问性能
- 提供快速的图像预处理能力

### 4. 视频拼接模块（stitcher.cpp）
- 将多路视频流拼接成单个画面（如4宫格布局）
- 在视频帧上叠加AI检测结果（边界框、标签）
- 添加时间戳和其他元数据信息
- 优化帧同步机制以减少延迟

### 5. 推流模块（streamer_thread.cpp）
- 使用GStreamer结合MPP硬件编码器进行H264编码
- 将拼接后的视频流推送到RTSP服务器（MediaMTX）
- 实现自适应帧率控制以平衡质量和性能
- 提供多种输出格式支持

## 多路视频流处理策略

### 1. 并行处理架构
- 每路视频流都有独立的拉流、推理和数据队列
- 不同流可以在不同的NPU核心上并行推理
- RGA支持多流并发处理

### 2. 队列管理
- 使用线程安全队列（ThreadSafeQueue）缓存视频帧
- 实现帧丢弃策略防止队列积压
- 优化队列大小以平衡延迟和流畅性

### 3. 资源调度
- 动态分配MPP解码/编码资源
- RGA核心负载均衡
- NPU计算资源合理分配

## 关键技术特性

### 1. 硬件加速
- **MPP**：硬件解码/编码，降低CPU负载
- **RGA**：硬件图像处理，加速格式转换和缩放
- **NPU**：AI推理加速，提供实时检测能力

### 2. 性能优化
- 非阻塞操作减少等待时间
- DMA32模式优化内存访问
- 多线程并行处理提升吞吐量
- 智能帧率控制平衡质量与性能

### 3. 系统稳定性
- 线程安全的数据交换机制
- 异常处理和资源清理
- 系统信号处理实现优雅退出

## RTSP服务集成

项目集成了MediaMTX作为RTSP服务器：
- 配置多路输入流接收
- 提供标准化RTSP接口
- 支持TCP/UDP传输协议
- 实现流媒体管理和转发

## 总结

RK3588 AI网关项目充分利用了RK3588 SoC的硬件加速能力，实现了高性能的多路视频AI分析系统。通过合理的多线程架构设计和硬件资源调度，系统能够在单个SoC上同时处理多路高清视频流的拉取、AI推理和推流，满足边缘AI计算的需求。
